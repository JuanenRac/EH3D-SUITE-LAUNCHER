# EH3D-SUITE-LAUNCHER: not yet

Good ideas that are not in the current version. Writing them here keeps anybody from implementing them early or twice.

| Idea | Why not yet | Revisit when |
|---|---|---|
| Discovering the machines of the workshop on the network | It needs the programs of the machines to announce themselves; today the launcher knows programs and projects only | the machine-control programs answer a discovery request |
| Calling the updater from the window | The updater belongs to another program and has its own window | the updater can be started with a project and tells what it did |
| A project as an archive that contains its files | The project points at the files with their checksum, which keeps it small and the files in place | a job has to travel to another computer as one file |
| Starting a program on another computer | It needs a way to start and watch a program on a machine that is not this one | the suite has a way to reach the programs of other machines |
| A look at the window on a screen of each system | The window was built and its logic tested, but no person has looked at it | a person opens it on each system |
